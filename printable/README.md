# OpenTransition Printable Journal

A physical, print-friendly version of the OpenTransition app that you can print and use as a tracking journal.

## 📄 Overview

This printable journal provides a tangible way to track your transition journey. It's designed for **5.5" x 8.5" paper** (half-letter size) with **professional printing bleed margins** included for services like VistaPrint.

**Print Options:**
- 🏠 **Home/Office Printing**: Print on standard or custom paper
- 🏢 **Professional Services**: Ready for VistaPrint, Printful, and print shops with 0.125" bleed
- 📄 **DIY Booklet**: Bind yourself with staples, rings, or spiral binding

The journal includes:

- 📸 **Photo tracking pages** for face, body, and custom areas
- 🎯 **Milestone pages** for medical, legal, social, and personal events
- 📊 **Comparison pages** to see your progress over time
- 📅 **Monthly calendars** for appointments and medication tracking
- 💭 **Reflection pages** for documenting your emotional journey
- 📝 **Notes pages** for free-form journaling

## 🖨️ How to Print

### Quick Start

1. **Open** `index.html` in your web browser (Chrome, Firefox, Safari, or Edge)
2. **Print** using your browser's print function (Ctrl+P or Cmd+P)
3. **Configure print settings**:
   - Paper size: **5.5" x 8.5"** (half-letter)
   - Orientation: Portrait
   - Margins: Default (the CSS handles spacing)
   - Color: Color or Black & White (both work well)
   - Pages: All pages

### Detailed Print Instructions

#### Chrome / Edge
1. Open `index.html` in Chrome or Edge
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. In the print dialog:
   - **Destination**: Choose your printer or "Save as PDF"
   - **Pages**: All
   - **Layout**: Portrait
   - **Color**: Color (recommended) or Black & white
   - **More settings**:
     - Paper size: Custom → 5.5 x 8.5 inches
     - Margins: Default
     - Scale: 100%
     - Options: Check "Background graphics" for colored boxes
4. Click **Print** or **Save**

#### Firefox
1. Open `index.html` in Firefox
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. In the print dialog:
   - **Destination**: Choose your printer or "Save to PDF"
   - **Orientation**: Portrait
   - **Paper Size**: Custom → Width: 5.5", Height: 8.5"
   - **Scale**: 100%
   - Check "Print backgrounds"
4. Click **Print** or **Save**

#### Safari (Mac)
1. Open `index.html` in Safari
2. Press `Cmd+P`
3. In the print dialog:
   - **Printer**: Choose your printer or "Save as PDF"
   - **Presets**: Default
   - **Paper Size**: Custom → 5.5" x 8.5"
   - Click "Show Details" for more options
   - Check "Print backgrounds"
4. Click **Print** or **PDF → Save as PDF**

### PDF Creation (Recommended)

We recommend saving as PDF first, then printing from the PDF:

1. Follow the print instructions above
2. Instead of selecting a printer, choose "Save as PDF" or "Microsoft Print to PDF"
3. Save the PDF file
4. Open the PDF in Adobe Reader or your PDF viewer
5. Print from the PDF viewer with custom paper size (5.5" x 8.5")

This ensures consistent formatting across different printers.

## 📐 Paper Options

### Half-Letter (5.5" x 8.5")
- **Recommended**: Standard half-letter size
- Easy to find or create by cutting letter paper in half
- Portable and convenient
- Fits in small binders or journals

### Creating Half-Letter Sheets

If you can't find pre-cut 5.5" x 8.5" paper:

1. **Option 1 - Print then Cut**:
   - Print on standard 8.5" x 11" letter paper
   - Cut each sheet in half to create 5.5" x 8.5" pages
   - Use a paper cutter for clean edges

2. **Option 2 - Print Shop**:
   - Save as PDF
   - Take the PDF to a print shop (FedEx Office, Staples, local printer)
   - Ask them to print on 5.5" x 8.5" paper or print and cut

3. **Option 3 - Custom Print Settings**:
   - Some printers support custom paper sizes
   - Check your printer manual for loading custom-sized paper

## 🎨 Paper & Binding Recommendations

### Paper Weight
- **20-24 lb** (standard): Good for everyday use, economical
- **28-32 lb** (heavy): More durable, premium feel
- **Cardstock** (65-110 lb): For cover page only

### Paper Type
- **Matte**: Best for writing, no glare
- **Bright white**: Great for color printing
- **Off-white/cream**: Easier on the eyes for reading

### Binding Options

1. **3-Ring Binder** (Recommended)
   - Punch holes in pages
   - Use a small 5.5" x 8.5" binder
   - Easy to add/remove pages
   - Can separate sections with dividers

2. **Spiral Binding**
   - Take to a print shop for spiral binding
   - Lays flat when open
   - Durable and professional look

3. **Folder/Portfolio**
   - Keep loose pages in a folder
   - Flexible and simple
   - Easy to reorganize

4. **DIY Binding**
   - Use a hole punch and ribbon/string
   - Japanese binding or coptic stitch
   - Creative and personal

## 💡 Usage Tips

### For Best Results

1. **Consistent Photos**
   - Take photos in the same lighting each time
   - Use the same angle and distance
   - Attach printed photos or use photo corners
   - Consider using a ring light or natural window light

2. **Regular Tracking**
   - Set a schedule (weekly, bi-weekly, or monthly)
   - Use calendar pages to plan photo days
   - Set phone reminders if needed

3. **Detailed Notes**
   - Write how you're feeling alongside photos
   - Note any changes in medication or lifestyle
   - Include both physical and emotional observations

4. **Privacy & Security**
   - Store in a locked drawer or safe
   - Consider keeping with a trusted friend if needed
   - Use the digital OpenTransition app with app lock for extra security

5. **Make It Yours**
   - Decorate pages with stickers or drawings
   - Use colored pens for different types of notes
   - Add extra pages as needed

### Multiple Copies

Consider printing multiple copies of:
- Photo tracking pages (print more as you need them)
- Monthly calendar (print one per month)
- Milestone pages (for ongoing documentation)
- Reflection pages (monthly use)

You can print individual pages by selecting page ranges in your print dialog.

## 🎨 Customization

### Editing the HTML

The journal is created using HTML and CSS, making it easy to customize:

- **Colors**: Edit `css/print-styles.css` and modify the CSS color variables
- **Fonts**: Change the `font-family` in the CSS
- **Layout**: Modify the HTML structure in `index.html`
- **Content**: Add or remove sections as needed

### Adding Your Own Pages

To add custom pages:

1. Open `index.html` in a text editor
2. Copy an existing page div: `<div class="page">...</div>`
3. Modify the content
4. Save and print

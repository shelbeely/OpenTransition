# Gallery

*Developer documentation for gallery feature.*

## Overview

The gallery provides a visual interface for browsing and comparing photos and audio recordings. It displays both image-based progress photos and voice recordings with their analysis data.

## Features

- Browse photos and audio recordings chronologically
- Filter by type (Face, Body, Audio)
- View audio waveforms and voice analysis data
- Play audio recordings directly from gallery
- Compare recordings side-by-side

See [Architecture Overview](../architecture/overview.md) for implementation details and [Voice Tracking](voice-tracking.md) for audio-specific gallery features.

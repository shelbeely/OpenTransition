# Import & Export

*Developer documentation for import/export functionality.*

## Overview

Data import/export allows users to backup and restore their data, including photos, audio recordings, voice analysis data, milestones, and settings.

## Export Format

Exports include:
- **Photos**: Image files and metadata
- **Audio Recordings**: Voice recording files (`.m4a`)
- **Voice Analysis**: Formant and pitch data (`AudioAnalysis` objects)
- **Milestones**: Event data and descriptions
- **Settings**: App preferences and configuration

See [Data Layer](../architecture/data-layer.md) for detailed format specifications and [Voice Tracking](voice-tracking.md) for audio-specific export details.

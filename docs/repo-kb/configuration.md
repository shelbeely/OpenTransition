# Configuration & Secrets

This page documents only **variable names, file locations, and purposes**. It never reveals real secret values.

## Source of Truth

| File | Tracked in git? | Purpose |
|---|---|---|
| [`build.gradle`](../../build.gradle) (root) | ✅ | Versions: Kotlin 2.0.20, Realm 2.3.0, Nav 2.8.5, AGP 8.13.0; app version constants |
| [`gradle.properties`](../../gradle.properties) | ✅ | AndroidX, Jetifier, parallel/cached builds |
| [`mobile/build.gradle`](../../mobile/build.gradle) | ✅ | Mobile module config, signing, KSP `room.schemaLocation` |
| [`wear/build.gradle`](../../wear/build.gradle) | ✅ | Wear module config |
| [`shared/build.gradle`](../../shared/build.gradle) | ✅ | Shared library config |
| [`secrets.properties.example`](../../secrets.properties.example) | ✅ | Template for `secrets.properties`. Contains AdMob **test** IDs only |
| `secrets.properties` | ❌ (gitignored / generated) | Real secrets in production builds; stubbed from the example for debug |
| `local.properties` | ❌ | Local SDK path (`sdk.dir=$ANDROID_SDK_ROOT`); generated by IDE or CI |
| `mobile/google-services.json` | ❌ in production form (a stub may be present in dev) | Firebase project configuration; injected in CI |
| [`keys/debug-keystore.jks`](../../keys/) | ✅ | Debug signing key (password `debugkey`, alias `transtracks`) |
| `keys/release-keystore.jks` | ❌ | Release signing key; generated from `KEYSTORE_64` secret in CI |

## CI Secrets

| Secret | Used by | Purpose |
|---|---|---|
| `KEYSTORE_64` | `ci.yml`, `build-release.yml` via `.github/ci-scripts/prepare-keystore.sh` | Base64-encoded release keystore |
| `STORE_PASS` | release builds | Keystore password |
| `KEY_ALIAS` | release builds | Signing key alias |
| `KEY_PASS` | release builds | Signing key password |
| (Firebase / AdMob secrets) | `prepare-secrets.sh`, `prepare-google-services.sh` | Real `secrets.properties` and `google-services.json` materialization |
| `BUILD_NUMBER` (env) | root `build.gradle` `getAppVersionCode` | CI sets this from `${{ github.run_number }}` |

The exact secret names are defined in [`.github/ci-scripts/`](../../.github/ci-scripts/) and the `env:` blocks of the workflow files. Do not echo any of these values.

## Generated-File Conventions

`copilot-setup-steps.yml` (and the docs in [`.github/copilot-instructions.md`](../../.github/copilot-instructions.md)) ensure the following before any build inside an agent runner:

1. `local.properties` exists and contains `sdk.dir=$ANDROID_SDK_ROOT`.
2. `secrets.properties` is stubbed from `secrets.properties.example`.
3. `mobile/google-services.json` is a **dummy** file safe for debug builds.
4. `gradlew` is executable (`chmod +x`).

## Build-Time Configuration

- `BuildConfig` generation is on (`gradle.properties`: `android.defaults.buildfeatures.buildconfig=true`).
- Room schemas exported to `mobile/schemas/` via the KSP arg `room.schemaLocation`.
- ProGuard/R8 rules: [`mobile/proguard-rules.pro`](../../mobile/proguard-rules.pro), [`wear/proguard-rules.pro`](../../wear/proguard-rules.pro). **Never weaken these without explicit instruction** ([`.github/copilot-instructions.md`](../../.github/copilot-instructions.md)).

## Hard Rules

- 🚫 Never commit real values for `secrets.properties`, `local.properties`, `mobile/google-services.json`, or `keys/release-keystore.jks`.
- 🚫 Never log or print secret values in workflow output, KB pages, or PR descriptions.
- ✅ Add new sensitive variable **names** here, with their purpose, when introducing them.

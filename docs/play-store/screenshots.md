# Screenshots Guide

*This page provides guidance for creating Play Store screenshots.*

## Recommended Screenshots

1. **Home Screen** - Show the main interface
2. **Gallery View** - Display photo organization
3. **Milestone List** - Show milestone tracking
4. **Photo Comparison** - Demonstrate progress tracking
5. **Settings** - Highlight customization options
6. **Privacy Features** - Show app lock/train mode

## Screenshot Specifications

- **Phone**: 1080 x 1920 pixels minimum
- **Tablet**: 1920 x 1080 pixels minimum  
- **Format**: PNG or JPEG
- **Maximum**: 8 screenshots per device type

## Tips

- Use actual app interface (no mockups)
- Show key features clearly
- Use consistent theme across screenshots
- Include captions explaining features
- Test on different screen sizes

# Privacy & Security

OpenTransition is built to keep your transition data private by default while giving you clear controls over any optional services.

## How Your Data Is Stored

- **Local-first:** Photos, milestones, and notes stay on your device unless you explicitly turn on cloud backup.
- **Optional cloud sync:** If you enable backup, data is stored in your Google account via Firebase Authentication and Firestore/Storage.

## Privacy Controls

- **App Lock & Disguised Icon (Train Mode):** Add a PIN/pattern lock and hide the app behind a train-themed icon.
- **Analytics & Crash Reports:** Both use Firebase and can be toggled in **Settings → Privacy**. They are enabled by default to improve stability.
- **Offline use:** All core features work without an account or network connection.
- **Export/Import:** Back up or move your data on your terms.

## Permissions Used

- **Camera (optional):** Capture photos directly in the app.
- **Photos/Storage:** Import existing photos and export backups.
- **Internet (optional):** Only used for cloud sync, analytics/crash reports, and ads (AdMob).

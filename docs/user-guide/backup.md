# Backup & Sync

*This page is under development. Check back soon for detailed backup instructions.*

## Quick Guide

**Local Backup:**
1. Settings → Backup & Sync
2. Export Data
3. Save the .ttbackup file

**Cloud Sync (Optional):**
1. Settings → Backup & Sync
2. Sign in with Google
3. Enable Cloud Sync

For now, see the [Getting Started Guide](getting-started.md#backing-up-your-data) for basic backup instructions.

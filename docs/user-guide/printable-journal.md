# Printable Journal

OpenTransition now includes a **physical, print-friendly journal** that you can print and use alongside or instead of the digital app. This gives you a tangible way to document your transition journey.

## Overview

The printable journal is designed for **5.5" × 8.5" paper** (half-letter size) and includes approximately 30 pages of tracking templates, milestone pages, and reflection prompts.

!!! tip "Perfect for..."
    - People who prefer physical journaling
    - Complementing your digital tracking
    - Creating a tangible keepsake
    - Situations where digital privacy is a concern
    - Gift giving to support friends on their journey

## What's Included

### Photo Tracking Pages

- **Comparison Pages** - Side-by-side progress views

### Milestone Documentation
- **Medical Milestones** - HRT start, dosage changes, appointments
- **Legal Milestones** - Name changes, gender marker updates
- **Social Milestones** - Coming out events, first days presenting
- **Personal Victories** - Celebrate your unique achievements

### Organization & Planning
- **Monthly Calendars** - Track appointments and photo schedules
- **Medication Tracker** - Document current medications and dosage changes
- **Appointment Log** - Record provider visits and outcomes
- **Resources & Contacts** - Keep important information handy

### Reflection & Growth
- **Monthly Reflection Pages** - Document physical and emotional changes
- **Goals & Intentions** - Set and track personal goals
- **Blank Notes Pages** - Free-form journaling space

## How to Print

### Quick Instructions

1. Open `printable/index.html` in your web browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Configure print settings:
    - **Paper Size**: 5.5" × 8.5" (Custom)
    - **Orientation**: Portrait
    - **Color**: Color or Black & White
    - **Margins**: Default
4. Enable "Print Backgrounds" or "Background Graphics"
5. Click Print or Save as PDF

!!! tip "Save as PDF First"
    We recommend saving as a PDF first for consistent formatting across printers:
    
    1. In the print dialog, select "Save as PDF"
    2. Save as `OpenTransition-Journal.pdf`
    3. Print from the PDF with custom paper size settings

### Detailed Browser Instructions

=== "Chrome/Edge"
    1. Open `index.html` in Chrome or Edge
    2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
    3. In print dialog:
        - **Destination**: Your printer or "Save as PDF"
        - **Layout**: Portrait
        - **Paper Size**: Custom → 5.5 × 8.5 inches
        - Check "Background graphics"
    4. Click Print or Save

=== "Firefox"
    1. Open `index.html` in Firefox
    2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
    3. In print dialog:
        - **Destination**: Your printer or "Save to PDF"
        - **Paper Size**: Custom → Width: 5.5", Height: 8.5"
        - Check "Print backgrounds"
    4. Click Print or Save

=== "Safari"
    1. Open `index.html` in Safari
    2. Press `Cmd+P`
    3. In print dialog:
        - **Paper Size**: Custom → 5.5" × 8.5"
        - Click "Show Details"
        - Check "Print backgrounds"
    4. Click Print or PDF → Save as PDF

## Paper Options

### Recommended: Half-Letter Size (5.5" × 8.5")

This is the ideal size for:
- Portability and convenience
- Easy binding with small binders
- Compact storage
- Cost-effective printing

### If You Don't Have Half-Letter Paper

**Option 1 - Print and Cut**

1. Print on standard 8.5" × 11" letter paper
2. Cut each sheet in half lengthwise
3. Use a paper cutter for clean, straight edges

**Option 2 - Print Shop**

1. Save the journal as a PDF
2. Take to FedEx Office, Staples, or a local print shop
3. Ask them to print on 5.5" × 8.5" paper or print and cut

**Option 3 - Custom Printer Settings**

Some printers support custom paper sizes - check your printer manual for instructions on loading custom-sized paper.

### Paper Weight Recommendations

| Weight | Best For | Notes |
|--------|----------|-------|
| 20-24 lb | Everyday use | Standard copy paper, economical |
| 28-32 lb | Premium feel | Heavier, more durable |
| Cardstock (65-110 lb) | Cover page only | Professional appearance |

## Binding Your Journal

Once printed, organize your pages with one of these methods:

### 🗂️ 3-Ring Binder (Recommended)
- Punch holes in pages
- Use a small 5.5" × 8.5" binder
- Easy to add/remove pages
- Can add divider tabs

### 🌀 Spiral Binding
- Take to a print shop for spiral binding
- Lays completely flat when open
- Durable and professional look
- Can't add pages later

### 📁 Folder or Portfolio
- Keep loose pages in a folder
- Most flexible option
- Easy to reorganize
- Simple and affordable

### ✂️ DIY Binding
- Use ribbon, string, or yarn
- Try Japanese binding or coptic stitch
- Creative and personalized
- Makes a unique keepsake

## Using Your Journal

### For Best Results

**Photo Consistency**
- Take photos in the same lighting each time
- Use the same angle and distance
- Attach printed photos with photo corners or tape
- Consider using a ring light or natural window light

**Regular Tracking**
- Set a consistent schedule (weekly, bi-weekly, monthly)
- Use calendar pages to plan photo days
- Set phone reminders if helpful

**Detailed Documentation**
- Write about how you're feeling alongside photos
- Note medication changes or life events
- Include both physical and emotional observations
- Celebrate all victories, big and small

**Privacy & Security**
- Store in a locked drawer or safe
- Keep with a trusted friend if needed
- Consider the digital app for sensitive information

## Customizing the Journal

The journal is built with HTML and CSS, making it easy to customize:

### Changing Colors

Edit `printable/css/print-styles.css` and modify these color variables:

```css
:root {
    /* OpenTransition Brand Colors */
    --primary-color: #E68322;        /* Orange */
    --primary-light: #FCF4ED;        /* Light cream */
    --primary-dark: #BC5A1E;         /* Dark brown */
    --secondary-color: #F9B21E;      /* Yellow */
    --secondary-light: #FFF8E7;      /* Light yellow */
    --tertiary-color: #BC5A1E;       /* Brown */
    --tertiary-light: #FFEEDD;       /* Light peach */
    --text-color: #3B3B3B;           /* Dark gray */
    --text-light: #6B6B6B;           /* Medium gray */
    --border-color: #D0D0D0;         /* Light border */
    --background: #3B3B3B;           /* Charcoal background (screen only) */
    --page-background: #FFFFFF;      /* White pages */
}
```

Note: The charcoal background (`--background`) is only visible on screen for a modern look. When printed, pages will have white backgrounds.

### Adding Custom Pages

1. Open `printable/index.html` in a text editor
2. Find a page similar to what you want to create
3. Copy the entire `<div class="page">...</div>` section
4. Modify the content to your needs
5. Save and print

### Changing Fonts

In `print-styles.css`, change the font-family:

```css
body {
    font-family: 'Your Font Name', 'Arial', sans-serif;
}
```

## Troubleshooting

### Pages Don't Fit Properly

- Ensure paper size is set to exactly 5.5" × 8.5"
- Check that margins are set to default (not custom)
- Verify print scale is set to 100%

### Colors Don't Print

- Enable "Background graphics" or "Print backgrounds" in print settings
- Some browsers call this "Print background colors and images"
- If printing in black & white, this is normal

### Text is Too Small/Large

- Check that print scale is 100%
- Try different paper weights (heavier paper can sometimes help)
- Verify your browser zoom is at 100% before printing

### PDF Looks Different from Browser

This is normal - PDFs render slightly differently. As long as the formatting looks good in the PDF, it will print correctly.
